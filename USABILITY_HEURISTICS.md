# Проверка по 10 эвристикам Нильсена

1. Видимость состояния: счётчики обновляются после действий.
2. Соответствие реальному миру: используются понятные подписи.
3. Контроль пользователя: задачи можно отметить и удалить.
4. Последовательность: повторяются единые стили кнопок и карточек.
5. Предотвращение ошибок: пустые задачи и заметки не сохраняются.
6. Узнавание вместо запоминания: действия видны на экране.
7. Гибкость: адаптивная сетка и быстрые формы.
8. Минимализм: ограниченная палитра и визуальная иерархия.
9. Восстановление после ошибок: показываются короткие уведомления.
10. Справка: README содержит инструкцию публикации.

Для production потребуются серверная авторизация, база данных, синхронизация, реальные уроки и тесты.
