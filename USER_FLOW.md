# User flow

1. Пользователь открывает главную страницу.
2. Просматривает три направления обучения.
3. Нажимает на курс и читает демонстрационное описание.
4. Добавляет задачи, отмечает их выполненными или удаляет.
5. Создаёт заметки, которые появляются в списке.
6. Задаёт отображаемое имя профиля.
7. Переключает светлую и тёмную тему.

Данные хранятся локально в браузере. Регистрация и синхронизация не реализованы.
